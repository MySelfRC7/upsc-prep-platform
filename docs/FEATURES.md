# Features Guide

## Overview

UPSC Preparation Platform provides a comprehensive solution for exam preparation with all essential resources integrated in one place.

## Core Features

### 1. Study Materials Library

**Description:** Centralized repository for all study materials.

**Features:**
- Upload PDFs (books, notes, summaries, guides)
- Organize by subject and topic
- Search and filter materials
- Download for offline access
- View count and popularity tracking

**How to Use:**
1. Go to "Study Materials"
2. Click "Upload" button
3. Select PDF file and choose subject/topic
4. Click "Upload"
5. Access anytime from library

### 2. Current Affairs Hub

**Description:** Stay updated with latest news relevant to UPSC.

**Features:**
- Auto-aggregation from major newspapers (The Hindu, Indian Express, Deccan Chronicle)
- Manual article uploads
- Category-wise organization (Polity, Economy, International, etc.)
- Search and filter by date
- Save important articles

**How to Use:**
1. Go to "Current Affairs"
2. View auto-scraped articles
3. Filter by category
4. Or upload your own summary
5. Bookmark important articles

### 3. Video Repository

**Description:** Organize and access educational videos.

**Features:**
- Upload downloaded videos
- Organize by subject and topic
- Play videos directly in platform
- Search and filter
- View count tracking

**How to Use:**
1. Go to "Videos"
2. Click "Upload" to add videos
3. Select topic
4. Click "Play" to watch
5. Bookmark important videos

### 4. Question Bank

**Description:** Comprehensive practice question bank with past papers and mock tests.

**Features:**
- MCQs from UPSC past papers
- Mock test sets
- Difficulty-wise categorization (Easy, Medium, Hard)
- Detailed explanations
- Instant feedback on answers
- Time tracking

**How to Use:**
1. Go to "Questions"
2. Filter by subject/year/difficulty
3. Click "Practice" to solve
4. See instant feedback
5. View analytics on performance

### 5. Progress Tracking

**Description:** Monitor your preparation progress.

**Features:**
- Track questions attempted
- Calculate accuracy percentage
- Subject-wise performance
- Time spent analysis
- Identify weak areas
- Performance graphs

**How to Use:**
1. Go to "Progress"
2. View overall statistics
3. Check subject-wise breakdown
4. Identify weak topics
5. Plan studies accordingly

### 6. Bookmarks & Favorites

**Description:** Save important resources for quick access.

**Features:**
- Bookmark questions, articles, materials, videos
- Quick access from dashboard
- Organize by category
- Easy removal

**How to Use:**
1. Click bookmark icon on any resource
2. Access from "Bookmarks" page
3. Remove when no longer needed

### 7. Search & Filter

**Description:** Find resources quickly.

**Features:**
- Full-text search across all content
- Filter by subject, topic, difficulty
- Filter by upload date
- Filter by resource type
- Sort by popularity, date, relevance

**How to Use:**
1. Use search bar on top
2. Type keyword
3. Use filters on left sidebar
4. Sort results as needed

### 8. Topic-wise Organization

**Description:** Organized structure following UPSC syllabus.

**Subjects:**
- Polity & Governance
- History
- Geography
- Economy & Finance
- Science & Technology
- Environment & Ecology
- International Relations
- Ethics & Integrity
- Current Affairs

**Each subject has multiple topics** with all resources linked together.

### 9. User Authentication

**Description:** Secure user accounts.

**Features:**
- User registration
- Login/Logout
- Profile management
- Password management

**How to Use:**
1. Click "Sign Up" for new account
2. Enter details
3. Verify email
4. Login with credentials
5. Access personalized dashboard

## Tips for Effective Preparation

1. **Organize Materials** - Keep resources organized by subject
2. **Regular Practice** - Practice questions daily
3. **Track Progress** - Monitor weak areas
4. **Review Explanations** - Understand concepts, don't just memorize
5. **Stay Updated** - Read current affairs regularly
6. **Use Bookmarks** - Save important resources for revision
7. **Time Management** - Track time spent on each topic
8. **Consistency** - Study consistently, avoid gaps

## FAQ

**Q: Can I download materials for offline use?**
A: Yes, you can download PDFs and videos for offline access.

**Q: How are current affairs updated?**
A: Current affairs are auto-scraped daily from major newspapers. You can also manually add articles.

**Q: Can I track my performance?**
A: Yes, go to "Progress" to see detailed analytics on your performance.

**Q: Can I create custom test sets?**
A: This feature is coming in Phase 2.

**Q: How is my data secured?**
A: All data is encrypted and stored securely. Your password is hashed.
